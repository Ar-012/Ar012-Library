### B. 当前分类混杂与疑似跨领域问题

- **“引擎与开发”全部是文档**：4项均不是引擎软件本体，因此没有“软件本体和文档实际混放”的证据，主要问题是标题可能让人期待引擎入口。UE5 Document与Unreal Engine Docs同属虚幻引擎文档，内容可能有交叉；它们是两个不同ID，不能直接称为重复实体，更不能据此合并。
- **“游戏美术 · Live2D”混合手册与教程**：两项都服务同一产品，但用途分别是查阅和学习。当前catalog没有对应Live2D Cubism软件本体，不能把手册当作动画工具本体。
- **“游戏美术”混合社区与素材**：GGAC、lospec与三个素材入口性质不同；OpenGameArt、itch.io Game Assets、Kenney Assets的描述还包含音频、工具等内容，范围超过纯美术。
- **“其他制作资源”混合工具与指南**：Machinations、Twine是制作工具；Xbox Accessibility Guidelines是检查与参考指南。Machinations虽涉及游戏设计，但描述明确强调设计、模拟和平衡工具，不能只因“设计”一词认定它属于学习资料。
- **“UI”混合工具、参考库和色板**：即时设计是通用UI/原型工具；GAME UI database是参考资料，不是可直接使用的游戏UI素材；Lospec Palette List是像素/复古游戏色板，描述不局限于UI。
- **“音频与音效”混合素材与工具**：前4项是素材，jsfxr、FMOD是制作工具；均已经共享到音频与视频。

**学习与研究 → 游戏设计的疑似交叉**：Live2D Cubism官方教程具有明确教学性质；GAME UI database和Xbox Accessibility Guidelines具有设计参考/指南性质，可供下一轮人工判断是否需要学习入口，但现有信息不足以认定必须从制作区移走。当前游戏设计学习视图中的MDA Framework、The Door Problem、GDKeys、Game Developer - Design、GDC Vault Free、好猫字幕组_语雀均未出现在这23项中。

**开发领域**：没有从名称和描述可明确识别的通用编程资源。引擎文档面向游戏制作，不因涉及开发流程就视为通用编程资料。

**音频与视频领域**：Freesound、Artlist、爱给网_音效配乐的描述没有限定游戏用途，具有通用音频素材属性；Sonniss GameAudioGDC、jsfxr、FMOD则明确强调游戏应用。六项已共享，无须将“共享”理解为分类错误或重复数据。

**其他领域**：即时设计具有通用UI设计用途，lospec与Lospec Palette List具有像素艺术/配色用途，GGAC具有游戏美术社区用途，可能与美术与设计交叉；这只是使用场景分析，当前没有这些ID在美术与设计的实际共享记录。本轮不移动，也不建立共享引用。
